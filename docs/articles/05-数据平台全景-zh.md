# A 股实时数据平台：Python · MCP · NATS 三种接入方式

> 覆盖 A 股实时行情、Level-2 订单簿、DDX 大单跟踪、资金流向、龙虎榜、市场资讯。
> 提供 **Python 原生 SDK · MCP Server · 底层 NATS 协议** 三种接入方式，
> 直接用于量化策略、AI Agent、数据分析或自建交易系统。

---

## 一、你在找哪种接入方式

根据你的使用场景，选择最合适的方式：

| 你的场景 | 推荐方式 | 接入方式 | 适合谁 |
|---|---|---|---|
| 写量化策略 / 回测 / Jupyter 分析 | **Python SDK** | `pip install pandastock` | 量化开发者、数据分析师 |
| 让 Claude / Cursor / Cline 直接查数据 | **MCP Server** | 配置到 MCP client | AI 应用开发者 |
| 嵌入到已有系统 / 自定义协议对接 | **NATS 协议** | 直接订阅/请求 | 全栈开发者、系统 integrator |
| 实时监控大屏 / 告警系统 | **NATS 推送** | 订阅行情主题 | 运维、实时系统 |

**三种方式底层是同一份数据源**——切换接入方式不需要重新申请账号。

## 二、数据能力覆盖

### 2.1 你能拿到什么数据

| 数据类型 | 具体内容 | 获取方式 | 实时性 | 对比 Tushare / Akshare |
|---|---|---|---|---|
| 个股列表 | 全市场股票代码/名称 | 请求 | 即时 | 持平 |
| 概念/行业板块 | 板块列表 | 请求 | 即时 | 持平 |
| 前复权 K 线 | 日/周/月/1/5/15/30/60 分钟 | 请求 | 即时 | 持平 |
| 实时分钟行情 | 1/5/15/30/60 分钟快照 | 请求 | **近实时** | Tushare 无实时 |
| 分笔成交 | 当日 / 历史逐笔 | 请求 | 即时 | Akshare 无 |
| 实时行情 | 全市场/个股/板块快照 | **推送** | **<1s** | Tushare 无实时 |
| Level-2 订单簿 | 十档委买委卖 + 逐笔 | **推送** | **<1s** | 无对标 |
| DDX 大单 | 主力净流入、异动 | **推送** | **<1s** | 无对标 |
| 资金流向 | 个股/市场主力、散户 | 推送+请求 | **近实时** | Akshare 有但无实时 |
| 龙虎榜 | 每日上榜席位 | 请求 | T+1 | 持平 |
| 市场资讯 | 核心财经/国内/国际 | 请求 | 近实时 | 无对标 |

### 2.2 为什么实时数据需要推送，不能轮询

```
轮询间隔 3s + 请求耗时 200ms = 最差延迟 3.2s
→ 全天 85%+ 请求拿到的是不变数据（停牌股、收盘后）
→ 请求越多 → 越容易被限流 → 被迫降频 → 延迟更大（恶性循环）
```

PandaStock 的架构是 **NATS 推送**：数据变化时主动推给订阅者。

```
推送延迟 = 网络传输（通常 <100ms）
→ 零无效请求
→ 标的不增加请求压力
→ 断线自动重连 + 补发断线期间数据
```

详细对比：[推送 vs 轮询的延迟实测](docs/articles/04-推送vs轮询-zh.md)

## 三、方式 A：Python SDK —— 直接在代码里用

### 3.1 适用场景

- 量化策略开发与回测
- Jupyter Notebook 数据分析
- 自建交易系统的数据层
- 定时报表 / 邮件日报
- 与 pandas、numpy、scikit-learn 直接集成

### 3.2 安装

```bash
pip install pandastock
```

依赖：`nats-py==2.14.0`（行情推送通道）。

### 3.3 两种数据模式

Python SDK 提供两类数据获取方式：

| 模式 | 方法 | 适用 |
|---|---|---|
| **请求-响应** | `get_ch_stock_front_day_history(code)` 等 | 历史 K 线、列表、快照查询 |
| **推送订阅** | `subscribe_ch_stock_real()` 等 + 自定义 Handler | 实时行情、Level-2、DDX |

### 3.4 请求-响应：拿历史数据和列表

```python
import pandastock as ps

# 初始化 + 连接（免费公共账号）
p = ps.PandaStock(phone="pandastock", nid="pandastock")
p.connect_server()

# 个股列表 / 概念 / 行业
stocks = p.get_ch_stock()
concepts = p.get_ch_concept()
industries = p.get_ch_industry()

# 前复权历史 K 线（日线 / 周线 / 月线）
daily = p.get_ch_stock_front_day_history("600519")
weekly = p.get_ch_stock_front_week_history("600519")
monthly = p.get_ch_stock_front_month_history("600519")

# 分钟线（1/5/15/30/60 分钟）
minute_real = p.get_ch_stock_minute_real("600519", minute=5)      # 实时分钟快照
minute_hist = p.get_ch_stock_minute_history("000001", minute=5, date="20263")  # 历史分钟

# 指数日线
index = p.get_ch_market_day_history("000300")   # 沪深300

# 概念/行业板块日线
concept_hist = p.get_ch_concept_day_history("BK0477")
industry_hist = p.get_ch_industry_day_history("BK0473")

# 分笔成交（当日实时 / 历史）
ticks_real = p.get_ch_stock_transaction_real("600519")
ticks_hist = p.get_ch_stock_transaction_history("600519", year="2026", month=3)

# 上证所市场汇总信息
daily_info = p.get_sh_market_daily_info("2026-10-10")
weekly_info = p.get_sh_market_week_info("2026-10-10")
monthly_info = p.get_sh_market_month_info("2026-10")
```

### 3.5 推送订阅：实时数据流

实时数据（个股行情、L2、DDX、板块、指数）通过 **NATS 推送**获取。你需要：

1. 继承 `TopicDataHandler`，重写对应回调
2. 调用 `subscribe_*` 订阅主题

```python
import pandastock as ps

class MyHandler(ps.TopicDataHandler):
    """自定义数据回调处理器"""

    def ch_stock_real(self, data):
        """A 股个股实时行情推送"""
        print(f"个股行情: {data}")

    def ch_market_real(self, data):
        """A 股指数实时行情推送"""
        print(f"指数行情: {data}")

    def ch_connect_real(self, data):
        """概念板块实时行情推送"""
        pass

    def ch_industry_real(self, data):
        """行业板块实时行情推送"""
        pass

    def ch_stock_l2_data_real(self, data):
        """Level-2 实时数据推送（十档委买委卖）"""
        print(f"L2: {data}")

    def ch_stock_ddx_data_real(self, data):
        """DDX 大单异动推送"""
        print(f"DDX: {data}")

    def ch_stock_l2_transaction(self, data):
        """L2 逐笔明细推送"""
        pass

    def ch_stock_l2_orders(self, data):
        """L2 委托明细推送"""
        pass

    def ch_stock_l2_depth(self, data):
        """L2 行情十档数据推送"""
        pass


# 初始化 + 注册处理器 + 连接
handler = MyHandler()
p = ps.PandaStock(phone="pandastock", nid="pandastock", handler=handler)
p.connect_server()

# 订阅实时主题
p.subscribe_ch_stock_real()       # 个股实时行情
p.subscribe_ch_market_real()      # 指数实时行情
p.subscribe_ch_concept_real()     # 概念板块实时
p.subscribe_ch_industry_real()    # 行业板块实时
p.subscribe_ch_l2_data_real()     # L2 实时数据
p.subscribe_ch_ddx_data_real()    # DDX 大单实时

# 订阅单股 L2 明细（十档/委托/逐笔）
p.subscribe_ch_l2_depth_single("600519")       # 茅台 L2 十档
p.subscribe_ch_l2_orders_single("600519")      # 茅台委托明细
p.subscribe_ch_l2_transaction_single("600519") # 茅台逐笔成交

# 批量订阅 / 全市场订阅
p.subscribe_ch_l2_depth_all()       # 全市场 L2 十档
p.subscribe_ch_l2_orders_all()      # 全市场委托
p.subscribe_ch_l2_transaction_all() # 全市场逐笔
```

程序保持运行，数据到达时自动触发回调。连接断开会自动重连。

## 四、方式 B：MCP Server —— 让 AI 工具直接查数据

### 4.1 适用场景

- Claude / GPT 对话中直接问股票问题
- Cursor / VS Code 中让 AI 辅助写策略
- Cline / Trae / Zed 等 AI 编辑器
- 不想写取数代码，让 AI 自己调

### 4.2 MCP 是什么

MCP（Model Context Protocol）让 AI 工具**直接调用外部数据接口**。

```
传统方式：你写代码取数据 → 复制给 AI → AI 分析
MCP 方式：你说「查茅台最近 20 天走势」→ AI 自动调接口 → AI 直接回答
```

### 4.3 22 个开放 MCP 工具

MCP Server 把底层能力封装为 AI 可直接调用的工具：

| 工具组 | 工具名 | 用途 |
|---|---|---|
| 实时 | `ChOneStockReal` / `ChStockCurReal` | 个股/全市场实时报价 |
| 实时 | `ChMarketCurReal` / `ChConceptCurReal` / `ChIndustryCurReal` | 市场/概念/行业实时行情 |
| 列表 | `chStockList` / `chConceptList` / `chIndustryList` | 代码/名称目录 |
| 历史 | `chStockFrontDayHistory` / `chStockMinuteHistory` / `ChMarketDayHistory` | 日线 + 分钟线 |
| 资讯 | `ChCoreNews` / `ChDomesticNews` / `ChGlobalNews` / `ChOptionNews` | 市场资讯 |
| 市场 | `ChLimitUpDown` / `ChLhbData` / `ChMarketFundFlow` / `chDdxStockData` | 涨跌停/龙虎榜/资金流/DDX |

### 5.5 推送 vs 请求的选择

| | 推送订阅 | 请求-响应 |
|---|---|---|
| 适用 | 实时流数据（行情/L2/DDX） | 一次性查询（历史/列表/快照） |
| 模式 | 被动接收回调 | 主动发请求、等响应 |
| 断线 | 自动重连 + 补发 | 需自行重试 |
| 延迟 | <100ms | 取决于网络 RTT |

## 六、与现有数据方案对比

### 6.1 定位差异

| 方案 | 实时能力 | Level-2 / DDX | 推送架构 |
|---|---|---|---|
| Tushare | ❌ T+1 | ❌ | — |
| Akshare | ⚠️ 分钟级 | ❌ | — |
| Baostock | ❌ T+1 | ❌ | — |
| JoinQuant / RiceQuant | ⚠️ 平台依赖 | ⚠️ 部分 | — |
| **PandaStock** | ✅ 推送 <1s | ✅ | NATS |

### 6.2 不是替代，是互补

```
离线研究（历史回测、因子挖掘）→ Tushare / Akshare
实时行情 + AI 交互 + 监控系统 → PandaStock
两者可以共存于同一套策略
```
